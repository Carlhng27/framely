# Framely

Small moments, framed well. An Instagram-style photo sharing MVP.

## Stack

Next.js 14 (App Router) · TypeScript · Tailwind CSS · SQLite (better-sqlite3)

## Features

- Feed of posts from demo users, newest first
- Like / unlike with an animated heart
- Post detail page with comments
- Upload a new post (image + caption)
- Profile grid per user
- Lightweight "switch demo user" session (no real auth) for trying different accounts

## Getting started

```bash
npm install
npm run dev
```

Visit http://localhost:3000. The SQLite database is created and seeded automatically on first run.
